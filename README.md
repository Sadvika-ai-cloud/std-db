## Student CRUD Application

A simple Student Management CRUD application built using Python Flask and SQLite. This project provides a web-based interface to manage student records.

 # 🚀 Features

- Add student records
- Search student records
- View student details
- Manage student information
- SQLite database integration
- Flask web application
- HTML templates using Jinja2
- Simple and user-friendly interface

## 🛠️ Technologies Used

- Python
- Flask
- SQLite
- HTML
- Jinja2
- Git
- GitHub

->How to Run
1. Clone the repository
git clone https://github.com/Sadvika-ai-cloud/std-db.git
2. Go to the project folder
cd std-db
3. Create a virtual environment
python -m venv crud_env
4. Activate the virtual environment
windows:
crud_env\Scripts\activate
5. Install Flask
pip install flask
6. Run the application
python app.py
7. Open in your browser
Usually Flask will show a local address such as:
http://127.0.0.1:5000/
Open that address in your browser.
